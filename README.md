# RAG_pipeline_in_local_machine
After studying more about LLMs and Indexes, and Vectors, Embeddings, semantic searches, my First attempt to put all together in a RAG. 

As some of us dont have API access to cloud hosted LLMs, its a good way to start with local LLMs, in my case i am using OLLAMA running locally. This acts as my LLM.

Make sure you had installed OLLAMA locally and its up and running before making calls. I am using ollama2 which is around 3 GB on disk and when loaded to RAM BOOM.. 9 GB..!!! my PC is 16 GB RAM and CPU based. struggling to copeup, but it works!! (slowly)
